# Durbar Group Contest 5

This repository contains my solutions for **Durbar Group Contest 5**, a JavaScript problem-solving contest focused on applying fundamental JavaScript concepts to practical coding problems.

The contest includes 10 different problems covering arrays, objects, strings, loops, conditions, built-in JavaScript methods, Date handling, Set, and queue operations.

## About the Contest

Durbar Group Contest 5 was designed to test practical problem-solving ability using JavaScript.

Instead of focusing only on syntax, the problems require understanding the given requirements, breaking the problem into smaller steps, choosing suitable JavaScript features, and producing the expected output.

I solved all 10 problems and kept each solution in a separate JavaScript file for easier understanding and reference.

## Problems Solved

### 1. Find Missing Number
Finds the missing number from an array containing numbers from `0` to `n`.

### 2. Format Attendance Report
Calculates attendance percentages and generates a formatted report with an attendance status.

### 3. Generate Profile Card
Creates a profile card while safely handling missing nested information using optional chaining and nullish coalescing.

### 4. Get Page Metadata
Calculates pagination information such as total pages, starting item, ending item, and whether previous or next pages exist.

### 5. Find Rainfall Peaks
Finds the days where the rainfall is higher than the rainfall of both neighboring days.

### 6. What Day Is It?
Determines the day of the week for a given date using JavaScript's `Date` object.

### 7. Common Skills of Two Candidates
Finds the skills shared by two candidates while handling case differences, removing duplicates, and sorting the result.

### 8. Swap Keys and Values
Creates a new object by swapping the keys and values of the original object.

### 9. Group Students by Grade Band
Groups students into `A`, `B`, `C`, and `F` grade bands based on their marks.

### 10. Ticket Queue Simulator
Simulates a ticket queue where people can join, leave, and be served while keeping track of served people.
